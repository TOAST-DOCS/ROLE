## 2023. 09. 26. { #september-26-2023 }
<a id="feature-updates"></a>
### 機能修正 { #feature-updates }
* Role作成時、Role idの命名ルールが変更されました。
    * Role idの最大文字数が従来の32文字から128文字に増えました。
    * 従来は`_`と`-`のみ許可されていた特殊文字が`.`と`:`も許可されるようになりました。
